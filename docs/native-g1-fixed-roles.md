## Joined source placements

The published implementation is in `native/hardening/coordinator-g1.patch` and its helper
`native/hardening/native-value-codec.h`, against the pinned TDLib revision. The patch now
includes OptionManager source/header as well as the existing candidate integration.

- **Original store:** temporary configuration is checked in TdDb before concurrent-store
  export and Global/OptionManager consumption. This does not claim that no native binlog/TL
  framing parser ran to populate quarantine.
- **Trusted mode:** `prepare_open` checks supplied mode against the retained storage binding.
  TdDb retains those parameters; the final binlog-actor continuation captures that mode by
  value. It neither infers mode from config nor calls G() during final validation.
- **Constructor:** a one-use pre-import check runs before option import, decoding, defaults
  or option updates. The default lambda has its own guard because it bypasses `set_option`.
  A refusal prevents further default writes; Td checks authority before subsequent startup
  owners and pending option requests. Constructor return is not required-owner completion.
- **Runtime writer:** the common setter checks before local-map mutation and config-PMC
  write/erase, including attempts to erase a fixed role. Failure revokes context authority
  synchronously and schedules ordinary G1 stop later, avoiding constructor/getter close
  re-entry. This is not an actual-resource-stop acknowledgement.
- **Consumers:** typed get-option completion validates before decoding/settling success;
  current-state projection validates its copied option set before appending updates. The
  underlying role entries are guarded at import and both constructor/common write paths.
  This does not certify unrelated native consumers or the whole initializer graph.
- **Seals:** complete group checks share the existing borrowed-view validator at capture
  and same-binlog-actor finalization. Guards are still released before sync/outward callbacks.
  Current selected semantic invalidity now precedes the healthy Changed stamp classification,
  including the existing auth, identity and retired-name checks—not just the new roles.

The PUBLIC helper owns only a presence mask and validity flag, not borrowed strings. Its
partial-group mode is solely the pristine NEW initial-import exception; both seals require
all members. No polling, retry cap, completion deadline or fairness policy is introduced.
